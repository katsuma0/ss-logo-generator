# ss logo generator

Pick two colours, get the ss logo in those colours. Downloads as a PNG with a transparent background (2000px wide) or as an SVG.

The colour boxes take hex with or without the `#`, three or six digits, or a CSS colour name like `tomato`.

`logo.svg` is the original in blue `#568BFC` and pink `#FF0073`. It was traced from the PNG, so the edges are a few pixels off from the source file. The blue half runs slightly under the pink one so no white seam shows where they meet.

It's one HTML file with no build step. GitHub Pages serves it from the root of `main`.
